PORTOFOLIO WEBSITE — HAZEL ARVIN

Cara menjalankan:
1. Ekstrak folder portfolio-website.zip.
2. Buka folder portfolio-website di Visual Studio Code.
3. Buka file index.html.
4. Klik kanan lalu pilih "Open with Live Server" (jika ekstensi Live Server terpasang).
   Alternatif: buka index.html langsung dengan browser.

Yang perlu dilengkapi:
- Tambahkan NIM jika diwajibkan oleh panduan.
- Tambahkan tautan GitHub dan LinkedIn bila sudah ada.
- Tambahkan prestasi, sertifikat, dan proyek yang benar-benar dimiliki.
- Periksa kembali nomor WhatsApp dan email sebelum dipublikasikan.
